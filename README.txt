# Mijn Voetbalstatistieken
Een eenvoudige mobiele voetbal-statistiekenapp.

## Gebruiken
Open `index.html` in een moderne browser. Op iPhone kun je via Delen → Zet op beginscherm een snelkoppeling maken.

## Gegevens
Alle ingevoerde wedstrijden worden lokaal op het apparaat opgeslagen. Via Profiel kun je een JSON-back-up exporteren en later weer importeren.

Deze eerste versie laat je zelf alle historische gegevens invoeren: seizoen, datum, tegenstander, thuis/uit, eindstand, minuten, doelpunten, assists, beoordeling en notitie.
